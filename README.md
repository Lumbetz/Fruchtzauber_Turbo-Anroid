# Fruchtzauber Android APK

GitHub Actions baut das lokale, offline spielbare Fruchtzauber mit WebView als Android-APK.

1. Neues GitHub-Repository `Fruchtzauber-Android` anlegen.
2. Alle Dateien und Ordner (einschließlich `.github`) aus diesem Projekt hochladen.
3. `Actions` > `Fruchtzauber Android APK` öffnen.
4. Nach erfolgreichem Build unter `Artifacts` das Archiv `Fruchtzauber-APK` laden.
5. Daraus `app-debug.apk` entpacken und auf Android installieren.

Hinweis: Debug-APK nur zur privaten Nutzung. Die Build-Ausführung wurde hier nicht auf GitHub getestet.
